# 简历项目描述

## 可直接用于简历的版本

**基于 STM32 与 MaixCAM 的智能视觉巡线小车｜独立项目**

技术栈：C / Python、STM32F103、FreeRTOS、MaixPy、UART、CRC16、PID、LoRa、CMake

独立完成智能巡线小车的视觉感知、运动控制、通信协议及整车集成，实现复杂赛道巡线、视觉检查点识别、雷达辅助避障与终点停车，完成完整赛道实车运行。

- **视觉与路线决策：** 基于多扫描带、动态 LAB 阈值及白底约束提取黑线路径，结合编码器里程、路径连续性和赛道拓扑完成分区选路；通过偏移与预瞄误差融合的分段 PID 生成转向指令。
- **嵌入式实时控制：** 基于 STM32 和 FreeRTOS 分离底盘控制与应用状态任务，实现 20 ms 配置周期的编码器反馈控制、舵机转向及内轮减速，集成速度限幅、命令超时停车和故障状态显示。
- **通信与验证：** 设计带 CRC16 校验的双向 UART 命令/遥测协议，接入雷达目标数据和 LoRa 检查点上报；实现串口错误恢复，通过 39 项 Python 回归测试、宿主 C 协议测试及 Debug / Release 固件构建验证。

项目链接：[github.com/Cevlan258/Track-line-Car](https://github.com/Cevlan258/Track-line-Car)

## 面试准备

建议结合源码讲清：为什么视觉与底盘分工、分段 PID 的误差来源、内轮减速与舵机的关系、坏帧和链路超时如何处理、为何将拱门视觉检测与雷达避障分离。

完整赛道运行及独立完成情况由作者确认。20 ms 是任务配置值，不是经过测量的最坏执行时间；150 ms 是超时配置阈值，不应写成保证的停车响应时间。未提供可复核的圈速、成功率或竞赛名次，因此本版本不包含此类数字。HAL、CMSIS、FreeRTOS、MaixPy 为使用的基础组件，独立项目不意味着这些组件由作者编写。
